# v0.5 Experience and Cost Design

Date: 2026-09-13

## Goal

Reduce routine bridge friction and repeated tokens while preserving one ordinary ChatGPT Chat as the semantic context owner and Codex as the local execution authority.

## Compact protocol

A new or migrated Chat receives one versioned protocol bootstrap. After the Chat acknowledges `compact-v1`, each request carries a native object delta and omits repeated format prose. Results retain the round identity fields and include only the fields required by the selected profile. Existing full schema-v2 exchanges remain readable.

Preparation fails closed until the bound Chat has acknowledged the current protocol. Chat migration resets the acknowledgement because protocol memory belongs to the conversation.

## App delivery adapter

The app adapter records the turn IDs visible immediately before send. It treats the send acknowledgement as queued, then matches only new turns containing the request idempotency key. Bounded polling can end in a recoverable state. Neither timeout nor resume permits resending the request.

## Cost accounting

The bridge estimates request, result, protocol, duplicated, and avoided-history tokens with a documented local heuristic. Metrics are useful for relative optimization and are not billing measurements. The ledger stays in project-local bridge state and produces no telemetry.

## User commands

- `status` shows bridge phase, delivery state, protocol state, and one next action.
- `resume` continues the safe recovery path and never resends.
- `inspect` summarizes a selected exchange; full stored content requires an explicit flag.
- `cost` reports per-round and aggregate token estimates.

Default command output omits the stored Chat reference. Machine-readable output is available through `--json true`.

## Acceptance criteria

- Compact requests and all five response profiles validate deterministically.
- A compact request cannot be prepared before protocol acknowledgement.
- Baseline turns cannot be mistaken for the response to a new request.
- Recovery never returns a resend instruction.
- Cost output exposes protocol share, duplicate rate, and avoided history.
- The four user commands work on both new and pre-v0.5 state.
- The complete package test and portable validation gates pass.
