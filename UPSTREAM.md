# Upstream provenance

This work is a direct derivative of [`anightmonarch/codex-bridge-chatgpt`](https://github.com/anightmonarch/codex-bridge-chatgpt), cloned from commit `56e36c2feeb6705376c1d1dc50dbec52ea43d4f4`.

The upstream one-shot Packet, Result, browser consent, Doctor, receipt, documentation, tests, assets, Git history, and MIT license remain the base. This derivative extends that base through versions 0.3–1.0 with persistent ordinary-Chat context, scoped state and migration, guarded artifact handling, mediated context access, local MCP, project setup, diagnostics, and reproducible release packaging. The change history and tests are included in this repository.

No claim is made that these local changes have been accepted or endorsed upstream.
